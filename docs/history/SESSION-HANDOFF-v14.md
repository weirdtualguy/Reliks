## Findings and decisions
- Priority is making Reliks useful, not DAG-City art. A user-visible demo comes before more infrastructure.
- Browser buy flow is BLOCKED, not built: kaspire.js line ~189 sets wrongnet for anything but mainnet; covenant spends have only been broadcast from Node over wRPC with a spoofed Origin header (a browser cannot set it; anchors wrpc list is empty); FEE_PER_BYTE (200 sompi) is a mainnet number and LANE_BUDGET 100 is from the Node builder; CORS from content:// to kascov/REST is untested; reliks-templates.js is hardwired to v12 ABIs and gen-site.js loops over JS engines only, so v13 needs its own page/template set (one template set per page).
- Wash result: the paper-veil wash is imperceptible at any cap that is not too washed. Formula is 3*(wear>0) + w*(510-w)*K/65025, so the first sale gives 3% and the next dozen add under 1%. Cap 50 and 30 looked too washed; cap 14 preview (wear 0/3/30/255 on edition #1) is visually identical across all four. Decision: do NOT deploy a new factory for this.
- What actually changes per sale is patina (roof accent colour, hashed from lineage): it reads as a random recolour, not aging. Layout comes from the serial. Both visible in the demo screenshots.
- kascov lags: after a mint, wait ~2 minutes before the next mint-v13.js or it fails with "lane UTXO not found". Check with the kascov /c/<C>.json live-utxo query before retrying. A failed run before broadcast spends nothing.
- secondary-v13.js: commands list|buy|unlist|transfer|sell. `sell <edIdx> <priceSompi>` sells to V.USER (self-sale) and advances lineage and sales (works; contract accepts buyer==owner; costs ~0.05 KAS royalty + fee per sale at 1 KAS). `transfer` advances lineage only. `unlist` and `transfer` write to a hardcoded v13/ledger-testnet-v13.json and ignore RELIKS_LEDGER: do not run them against the VM ledger until fixed.
- Earlier v13 status from handoff v13: verified on testnet-10 except spend/burn and the escrow-accept negative test; transfer advances lineage (sales unchanged); zero-price sell removed; escrow is v6.
